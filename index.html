Sync from Google Sheet

  1. Open your Google Sheet → File → Share → Publish to web
  2. Select the sheet, choose CSV as the format, then click Publish
  3. Paste the link you get into the box below

Note: this dashboard is fully static (no server). Any changes you make — editing, adding, or syncing from Google Sheet — are saved only in this browser on this device, not shared with other visitors automatically. To keep every device in sync, sync from the same published Google Sheet on each device after making changes there. The admin password only stops casual users from editing — if sensitive data (like Aadhaar numbers) is included, only share this link with people you trust.
